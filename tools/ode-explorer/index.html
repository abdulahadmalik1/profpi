    No eval, ever

    Every expression goes through a real tokenizer → recursive-descent parser → tree-walking evaluator over a fixed, whitelisted grammar. Malformed or hostile input can only ever produce a clean rejected-parse — never code execution.

    Bounded by design

    Grid size, Newton iterations, and trajectory length all have hard caps, so nothing you type — accidentally or on purpose — can hang your browser or a shared server.

    Runs on tested math

    Every routine (RK4 integration, root finding, eigenvalue classification) is covered by an automated test suite and a 2,600+ case fuzz suite before it ever reaches this page.
